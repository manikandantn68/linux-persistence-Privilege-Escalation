THE FOUR COMPILATION STAGES IN C

1. PREPROCESSING
   Input: program.c
   Output: program.i
   - Processes #include files.
   - Expands #define macros.
   Command: gcc -E program.c -o program.i

what is -e -> execute only the preprocessing stage and stop after preprocessing

2. COMPILATION
   Input: program.i
   Output: program.s
   - Converts C code into assembly code.
   Command: gcc -S program.i -o program.s

3. ASSEMBLY
   Input: program.s
   Output: program.o
   - Converts assembly code into machine code.
   Command: gcc -c program.s -o program.o

4. LINKING
   Input: program.o
   Output: Executable file
   - Combines object files and required libraries.
   Command: gcc program.o -o program

RUN THE PROGRAM
   ./program

COMPILATION FLOW
   program.c
      ↓
   Preprocessing
      ↓
   program.i
      ↓
   Compilation
      ↓
   program.s
      ↓
   Assembly
      ↓
   program.o
      ↓
   Linking
      ↓
   Executable

ONE-COMMAND COMPILATION
   gcc program.c -o program

REMEMBER:
   Preprocessing → Compilation → Assembly → Linking

Rules for Defining Variables in C

Rule 1: A variable name must begin with a letter or underscore.
int age;       // Valid
int _count;    // Valid
int 1age;      // Invalid


Rule 2: A variable name can contain letters, digits, and underscores.
int student1;     // Valid
int student_age;  // Valid
int student-age;  // Invalid
int student age;  // Invalid

Rule 3: Spaces are not allowed in variable names.
int total_marks;  // Valid
int total marks;  // Invalid

Rule 4: C keywords cannot be used as variable names.
int float;  // Invalid
int return; // Invalid
int number; // Valid

Rule 5: Variable names are case-sensitive.
int age = 20;
int Age = 25;
int AGE = 30;

2. Variable declaration rules

Rule 7: A variable must have a data type
int age;
float price;
char grade;


Rule 8: A variable must be declared before it is used.
int main()
{
    int age = 20;
    printf("%d", age);
    return 0;
}

Rule 9: A declaration normally ends with a semicolon (;).

int age = 20;

Rule 10: A variable may be initialized when it is declared.
int age = 20;  // Initialized
int marks;     // Declared but not initialized

-------
A local variable is declared inside a function or a block. It can normally be accessed only within that function or block.

example :
#include <stdio.h>

int main()
{
    int age = 20;  // Local variable

    printf("%d\n", age);

    return 0;
}

----------

A global variable is declared outside all functions. It can be accessed by functions in the same source file after its declaration, subject to scope and other rules.


ex :
#include <stdio.h>

int age = 20;  // Global variable

void display()
{
    printf("%d\n", age);
}

int main()
{
    display();
    printf("%d\n", age);

    return 0;
}





---------
A static local variable is declared inside a function or block. It can be accessed only within that scope, but it retains its value between function calls.

{
    static int count = 0;

    count++;

    printf("%d\n", count);

    counter();

    return 0;

C DATA TYPES

A data type specifies the kind of value a variable can represent.

1. PRIMARY (BASIC) DATA TYPES

char     - Character and small integer values
int      - Integer values
float    - Floating-point values
double   - Floating-point values with greater precision
_Bool    - Boolean values (0 or 1)
void     - No value or no specific type

Examples:
int age = 20;
float price = 10.5f;
double pi = 3.14159;
char grade = 'A';
Bool active = 1;


2. NON-PRIMARY DATA TYPES

Non-primary is a broad textbook term, not an official C category.

It can refer to types other than basic types, including
derived types and user-defined types.


3. DERIVED DATA TYPES

Array     - Collection of elements of the same type
Pointer   - Holds a memory address
Function  - Has a return type and parameter types

Examples:
int numbers[5];
int *ptr;
int add(int, int);


4. USER-DEFINED TYPES AND TYPE ALIASES

struct   - Groups multiple members
union    - Allows members to share storage
enum     - Defines named integer constants
typedef  - Creates an alias for an existing type

Examples:
struct Student { int age; };
union Data { int number; float value; };
enum Color { RED, GREEN, BLUE };
typedef unsigned int uint;


IMPORTANT

- Non-primary is not an official C language category.
- Arrays, pointers, and functions are derived types.
- Structures, unions, and enumerations provide ways
  to define types.
- typedef creates an alias, not a new distinct type.

A do-while loop in C executes a block of code first and checks the condition afterward. Therefore, the loop body executes at least once, even if the condition is false initially.

#include <stdio.h>

int main(void)
{
    int i = 1;

    {
        printf("%d\n", i);
        i++;

----------------------------------------------
A for loop in C is used to execute a block of code repeatedly while a condition remains true. It is commonly used when you know how many times you want to repeat an operation.

The three parts are:
- Initialization: Sets the starting value.
- Condition: Determines whether the loop continues.
- Update: Changes the loop variable after each iteration.

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

fork() is a system call used to create a new process. The new process is called the child process, and the original process is called the parent process.

ex:
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main(void)
{
    pid_t pid = fork();

    if (pid < 0)
    {
        printf("Fork failed!\n");
        return 1;
    }
    else if (pid == 0)
    {
        printf("I am the child process.\n");
    }
    else
    {
        printf("I am the parent process.\n");
        wait(NULL);
    }

    return 0;
}


---------
fork() asks the operating system to create a child process. After a successful call, both parent and child continue executing from the next statement.


ex:
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>

int main(void)
{
    pid_t pid = fork();

    if (pid == 0)
    {
        printf("I am the child process.\n");
    }
    else if (pid > 0)
    {
        printf("I am the parent process.\n");
        printf("Child PID: %d\n", (int)pid);
    }
    else
    {
        perror("fork");
        return 1;
    }

    return 0;
}

execve() — Execute a program

execve() replaces the current process's program image with another program. On success, it does not return to the original code.

#include <unistd.h>
#include <stdio.h>

int main(void)
{
    char *args[] = {"ls", "-l", NULL};
    char *env[] = {NULL};

    execve("/bin/ls", args, env);

    perror("execve");
    return 1;
}
The perror() line runs only if execve() fails.
- "/bin/ls" — path to the executable.
- args — argument list, terminated by NULL.
- env — environment variable list, terminated by NULL. This example supplies an empty environment.

Time Complexity
Time complexity estimates how many basic operations an algorithm performs as a function of input size 
It answers: “If the input gets much larger, how much slower does this algorithm get?”

 Space Complexity
Space complexity estimates how much extra memory an algorithm needs as a function of input size
It answers: “If the input gets much larger, how much more memory does this algorithm need?”

Time complexity measures how an algorithm’s running time grows with input size, and space complexity measures how its memory usage grows with input size—both usually described using Big O notation.

A Stack is a linear data structure that follows LIFO (Last In, First Out). It stores elements and allows insertion and removal from the same end, called the TOP.

stack is depend on array ?
No. A stack is an abstract idea (push, pop, peek, LIFO). You can build it with an array or a linked list.




#include <stdio.h>

#define MAX 5

int stack[MAX];
int top = -1;

// Insert an element into the stack
void push(int value)
{
    if (top == MAX - 1)
    {
        printf("Stack Overflow! Stack is full.\n");
        return;
    }

    stack[++top] = value;
    printf("%d pushed into stack.\n", value);
}

// Remove the top element
void pop(void)
{
    if (top == -1)
    {
        printf("Stack Underflow! Stack is empty.\n");
        return;
    }

    printf("%d popped from stack.\n", stack[top--]);
}

// View the top element
void peek(void)
{
    if (top == -1)
    {
        printf("Stack is empty.\n");
        return;
    }

    printf("Top element: %d\n", stack[top]);
}

// Display all elements from top to bottom
void display(void)
{
    if (top == -1)
    {
        printf("Stack is empty.\n");
        return;
    }

    printf("Stack (top to bottom):\n");

    for (int i = top; i >= 0; i--)
    {
        printf("| %d |\n", stack[i]);
    }
}

int main(void)
{
    int choice, value;

    while (1)
    {
        printf("\n--- STACK MENU ---\n");
        printf("1. PUSH\n");
        printf("2. POP\n");
        printf("3. PEEK\n");
        printf("4. DISPLAY\n");
        printf("5. EXIT\n");
        printf("Enter your choice: ");

        if (scanf("%d", &choice) != 1)
        {
            printf("Invalid input.\n");
            return 1;
        }

        switch (choice)
        {
            case 1:
                printf("Enter value: ");

                if (scanf("%d", &value) != 1)
                {
                    printf("Invalid input.\n");
                    return 1;
                }

                push(value);
                break;

            case 2:
                pop();
                break;

            case 3:
                peek();
                break;

            case 4:
                display();
                break;

            case 5:
                printf("Program terminated.\n");
                return 0;

            default:
                printf("Invalid choice. Try again.\n");
        }
    }
}


Important variables and operations
stack[MAX]	Stores stack elements
top = -1	Indicates an empty stack
push()	Adds an element
pop()	Removes the top element
peek()	Reads the top element without removing it
display()	Prints elements from top to bottom


question:
first in first out ? Last In, First Out ? both are stack ?

No. FIFO and LIFO are two different principles used by two different data structures.

Stack ->Last In, First Out
Queue -> First In, First Out

Final answer: Both are linear data structures, but LIFO is the standard principle of a stack, while FIFO is the standard principle of a queue.

#include <stdio.h>
#include <stdlib.h>

struct node
{
    int data;
    struct node *next;
};

struct node *head = NULL;
struct node *tail = NULL;

// Add an element at the end of the list
void insert(int value)
{
    struct node *new = malloc(sizeof(struct node));

    if (new == NULL)
    {
        printf("Memory allocation failed.\n");
        return;
    }

    new->data = value;
    new->next = NULL;

    if (head == NULL)
        head = new;              // first node
    else
        tail->next = new;        // link after last node

    tail = new;
    printf("%d inserted into list.\n", value);
}

// Remove the first node that has the given value
void removeNode(int value)
{
    struct node *temp = head;
    struct node *prev = NULL;

    if (head == NULL)
    {
        printf("List is empty.\n");
        return;
    }

    while (temp != NULL && temp->data != value)
    {
        prev = temp;
        temp = temp->next;
    }

    if (temp == NULL)
    {
        printf("%d not found in list.\n", value);
        return;
    }

    if (prev == NULL)
        head = temp->next;       // removing first node
    else
        prev->next = temp->next; // skip over the node

    if (temp == tail)
        tail = prev;             // removing last node

    free(temp);
    printf("%d removed from list.\n", value);
}

// Display all elements from first to last
void display(void)
{
    struct node *temp = head;

    if (head == NULL)
    {
        printf("List is empty.\n");
        return;
    }

    printf("List: ");

    while (temp != NULL)
    {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }

    printf("NULL\n");
}

// Free all nodes before exit
void clearList(void)
{
    struct node *temp;

    while (head != NULL)
    {
        temp = head;
        head = head->next;
        free(temp);
    }
}

int main(void)
{
    int choice, value;

    while (1)
    {
        printf("\n--- LINKED LIST MENU ---\n");
        printf("1. INSERT\n");
        printf("2. REMOVE\n");
        printf("3. DISPLAY\n");
        printf("4. EXIT\n");
        printf("Enter your choice: ");

        if (scanf("%d", &choice) != 1)
        {
            printf("Invalid input.\n");
            clearList();
            return 1;
        }

        switch (choice)
        {
            case 1:
                printf("Enter value: ");

                if (scanf("%d", &value) != 1)
                {
                    printf("Invalid input.\n");
                    clearList();
                    return 1;
                }

                insert(value);
                break;

            case 2:
                printf("Enter value to remove: ");

                if (scanf("%d", &value) != 1)
                {
                    printf("Invalid input.\n");
                    clearList();
                    return 1;
                }

                removeNode(value);
                break;

            case 3:
                display();
                break;

            case 4:
                clearList();
                printf("Program terminated.\n");
                return 0;

            default:
                printf("Invalid choice. Try again.\n");
        }
    }
}

double linked list

#include <stdio.h>
#include <stdlib.h>

struct node
{
    int data;
    struct node *prev;
    struct node *next;
};

struct node *head = NULL;
struct node *tail = NULL;

// Add an element at the end of the list
void insert(int value)
{
    struct node *new = malloc(sizeof(struct node));

    if (new == NULL)
    {
        printf("Memory allocation failed.\n");
        return;
    }

    new->data = value;
    new->prev = tail;            // points back to old last node
    new->next = NULL;

    if (head == NULL)
        head = new;              // first node
    else
        tail->next = new;        // link after last node

    tail = new;
    printf("%d inserted into list.\n", value);
}

// Remove the first node that has the given value
void removeNode(int value)
{
    struct node *temp = head;

    if (head == NULL)
    {
        printf("List is empty.\n");
        return;
    }

    while (temp != NULL && temp->data != value)
        temp = temp->next;

    if (temp == NULL)
    {
        printf("%d not found in list.\n", value);
        return;
    }

    if (temp->prev == NULL)
        head = temp->next;               // removing first node
    else
        temp->prev->next = temp->next;   // previous skips this node

    if (temp->next == NULL)
        tail = temp->prev;               // removing last node
    else
        temp->next->prev = temp->prev;   // next skips this node

    free(temp);
    printf("%d removed from list.\n", value);
}

// Display all elements from first to last
void displayForward(void)
{
    struct node *temp = head;

    if (head == NULL)
    {
        printf("List is empty.\n");
        return;
    }

    printf("Forward : NULL <-> ");

    while (temp != NULL)
    {
        printf("%d <-> ", temp->data);
        temp = temp->next;
    }

    printf("NULL\n");
}

// Display all elements from last to first
void displayBackward(void)
{
    struct node *temp = tail;

    if (tail == NULL)
    {
        printf("List is empty.\n");
        return;
    }

    printf("Backward: NULL <-> ");

    while (temp != NULL)
    {
        printf("%d <-> ", temp->data);
        temp = temp->prev;
    }

    printf("NULL\n");
}

// Free all nodes before exit
void clearList(void)
{
    struct node *temp;

    while (head != NULL)
    {
        temp = head;
        head = head->next;
        free(temp);
    }
}

int main(void)
{
    int choice, value;

    while (1)
    {
        printf("\n--- DOUBLE LINKED LIST MENU ---\n");
        printf("1. INSERT\n");
        printf("2. REMOVE\n");
        printf("3. DISPLAY FORWARD\n");
        printf("4. DISPLAY BACKWARD\n");
        printf("5. EXIT\n");
        printf("Enter your choice: ");

        if (scanf("%d", &choice) != 1)
        {
            printf("Invalid input.\n");
            clearList();
            return 1;
        }

        switch (choice)
        {
            case 1:
                printf("Enter value: ");

                if (scanf("%d", &value) != 1)
                {
                    printf("Invalid input.\n");
                    clearList();
                    return 1;
                }

                insert(value);
                break;

            case 2:
                printf("Enter value to remove: ");

                if (scanf("%d", &value) != 1)
                {
                    printf("Invalid input.\n");
                    clearList();
                    return 1;
                }

                removeNode(value);
                break;

            case 3:
                displayForward();
                break;

            case 4:
                displayBackward();
                break;

            case 5:
                clearList();
                printf("Program terminated.\n");
                return 0;

            default:
                printf("Invalid choice. Try again.\n");
        }
    }
}

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *tail = NULL;   // last node; tail->next is the first node

void insert(int value) {
    struct Node *n = malloc(sizeof(struct Node));
    n->data = value;
    if (tail == NULL) {
        n->next = n;             // first node points to itself
    } else {
        n->next = tail->next;    // new node -> first node
        tail->next = n;          // old last -> new node
    }
    tail = n;                    // new node becomes the last
}

void display() {
    if (tail == NULL) return;
    struct Node *p = tail->next;         // start at first node
    do {
        printf("%d -> ", p->data);
        p = p->next;
    } while (p != tail->next);           // stop when back at the start
    printf("(back to first)\n");
}

int main() {
    insert(10);
    insert(20);
    insert(30);
    display();
    return 0;
}
