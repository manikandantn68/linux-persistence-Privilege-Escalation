Volatility 3 :Understand the common arguments 
vol                    ->Starts Volatility 3
-s                     ->Specifies the directory containing kernel symbol tables
./vol3-symbols ->Your CentOS kernel ISF symbol directory
-f	               -> Specifies the memory dump to investigate
./dump.mem  ->The captured Linux memory image
PLUGIN          -> The forensic operation you want to perform

vol -s ./vol3-symbols -f ./dump.mem PLUGIN

Plugin: banners.Banners
Purpose:
- Searches memory for Linux kernel banner strings.
- Identifies the kernel version.
- Helps identify the kernel build and architecture.

Plugin: linux.bash.Bash
Purpose:
- Recovers Bash command history from memory.
- Displays commands executed by users.
- Helps identify attacker activity.

Plugin: linux.pslist.PsList
Purpose:
- Enumerates processes present in memory.
- Identifies process IDs and parent-child relationships.
- Helps identify suspicious processes.

Plugin: linux.sockstat.Sockstat
Purpose:
- Enumerates network sockets.
- Identifies local and remote IP addresses.
- Displays local and remote ports.
- Shows connection states.


Plugin: linux.psaux.PsAux
Purpose:
- Retrieves process command-line information.
- Displays arguments supplied when processes were started.
- Helps identify suspicious commands and execution techniques.


Plugin: linux.proc.Maps
Purpose:
- Enumerates a process's virtual memory areas (VMAs).
- Shows mapped memory regions.
- Can dump the selected process's memory regions.


Plugin: linux.lsmod.Lsmod
Purpose:
- Enumerates loaded Linux kernel modules.
- Displays module names and memory information.
- Helps investigate potentially malicious kernel modules.

7.Which technique does the malware use to store strings before decrypting them?

Stack strings

What are stack strings?
Stack strings are a technique where a program constructs strings directly in stack memory using instructions instead of storing them as readable strings in the binary.

Encrypted string bytes
        |
        v
Construct values on stack
        |
        v
Call decryption function
        |
        v
Decrypt string
        |
        v
Use plaintext string

Why malware uses this: It makes static string analysis harder because readable strings are not directly visible through tools such as strings

Step 1: Extract the compressed disk image

gunzip     -> Decompresses the .gz file.
-k         -> Keeps the original compressed file.

Creates disk.flag.img without deleting disk.flag.img.gz.


Step 2: Examine the partition table

Command:
mmls disk.flag.img

Explanation:
mmls -> Displays the partition layout of the disk image.
disk.flag.img -> Disk image to investigate.

Purpose:
Identifies the partitions and their starting sectors.

Target partition offset:
360448


Step 3: Find flag files

Command:
fls -r -o 360448 disk.flag.img | grep -i flag

Explanation:
fls      -> Lists files and directories in the filesystem.
-r       -> Recursively searches subdirectories.
-o       -> Specifies the filesystem starting sector offset.
360448   -> Starting sector of the target partition.
disk.flag.img -> Disk image.
|        -> Sends fls output to grep.
grep     -> Searches text for a matching pattern.
-i       -> Case-insensitive search.
flag     -> Search keyword.

Example output:
r/r * 2082(realloc): flag.txt
r/r 2371: flag.uni.txt

Explanation:
r/r      -> Regular file.
2082     -> Metadata address (inode number).
2371     -> Metadata address (inode number).
*        -> Indicates a deleted file entry.
flag.uni.txt -> Target filename.


Step 4: Extract the file using its inode

Command:
icat -o 360448 disk.flag.img 2371

Explanation:
icat     -> Extracts file content using its inode number.
-o       -> Specifies the filesystem starting sector offset.
360448   -> Starting sector of the target partition.
disk.flag.img -> Disk image.
2371     -> Inode number of the target file.

Purpose:
Uses the inode to locate the file's data blocks and extract its content.

Output:
Displays the extracted file content in the terminal.


Step 5: Save the extracted content into a file

Command:
icat -o 360448 disk.flag.img 2371 > flag.txt

Explanation:
>        -> Redirects command output into a file.
flag.txt -> Saves the extracted content.

Display the extracted content:
